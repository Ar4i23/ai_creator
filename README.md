# your.story — сайт-прайс AI creator

Одностраничный сайт-прайс для создателя сюжетных ИИ-роликов и мультфильмов:
реклама, которая выглядит как история — продукт внутри сюжета, постоянные
персонажи, серийный прогрев аудитории.

## Технологии и подход

- **БЭМ** — все классы по методологии Блок**Элемент--Модификатор
  (`package-card**price`, `menu--open`, `form\_\_group--invalid`…).
- **CSS-модули**: стили разбиты на файлы по блокам и собраны в одном
  `css/style.css` через `@import` — к HTML подключён только он.
- **Mobile-first адаптив**: базовые стили + все медиазапросы в `modules/media.css`
  (560 / 640 / 768 / 900 / 1200 / 1600 px).
- **JS-модули** (`type="module"`): `theme.js`, `menu.js`, `form-validation.js`.
- **Темы**: базовая — тёмный неон (как в референсе), переключатель на светлую;
  выбор сохраняется в `localStorage`.
- **SEO**: `lang="ru"`, title/description/keywords, Open Graph, favicon,
  семантика (`header/main/section/article/footer`), один `h1`, осмысленные `alt`,
  микроразметка Schema.org (`ProfessionalService` + цены).
- **Форма заявки** с валидацией в реальном времени: ошибки под полями,
  кнопка заблокирована до валидного состояния, сообщение об успехе.

## Структура страницы

1. Шапка: логотип, навигация, переключатель темы, CTA.
2. Hero: заголовок, оффер, кнопки, бейджи преимуществ.
3. Почему сюжетные ролики (6 преимуществ).
4. Форматы работы (5 карточек).
5. Пакеты и цены (3 пакета + VIP).
6. Примеры работ (6 карточек со стилями).
7. Почему выбирают меня + результаты в Instagram.
8. Этапы работы (6 шагов).
9. FAQ (аккордеон).
10. Форма заявки.
11. Подвал: навигация, контакты, дисклеймеры.

## Запуск

ES-модули не работают с `file://` — используйте локальный сервер:

```bash
npx serve .
# или расширение Live Server в VS Code
```

## Кастомизация

- **Цены и состав пакетов** — секция `#packages` в `index.html`.
- **Тема по умолчанию** — атрибут `data-theme` у `<html>`
  (`dark` — неон, `light` — светлая) + инлайн-скрипт в `<head>`.
- **Контакты** — подвал и ссылки `t.me / vk.com / mailto`.
- **Фото и видео-превью** — папка `img/` (замените заглушки на свои кадры).
